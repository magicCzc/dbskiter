# dbskiter - 依赖说明
#
# 所有依赖已统一管理在 pyproject.toml 的 [project.dependencies] 和
# [project.optional-dependencies] 中。
#
# 安装方式：
#   pip install dbskiter                    # 核心依赖
#   pip install dbskiter[dev]               # 含开发工具
#   pip install dbskiter[oracle]            # 含 Oracle 支持
#   pip install dbskiter[web]               # 含 Web UI
#
# 本地开发安装：
#   pip install -e ".[dev]"
